INÍCIO

1. Configurar ambiente
    Verificar disponibilidade da GPU.
    Importar bibliotecas necessárias.

2. Configurar projeto
    Definir:
        Diretórios de entrada e saída.
        Arquivo de anotações do COCO.
        Classes de interesse.
        Quantidade máxima de imagens por classe.
        Mapeamento das classes para o formato alvo.

3. Preparar estrutura do dataset
    Criar diretórios de saída.
    Remover arquivos de execuções anteriores.

4. Carregar conjunto de dados
    Ler o arquivo de anotações COCO.
    Organizar imagens e anotações na memória.

5. Selecionar imagens
    Filtrar apenas as classes de interesse.
    Descartar anotações inválidas.
    Balancear a quantidade de imagens entre as classes.

6. Processar e converter anotações
    Para cada imagem selecionada:
        Copiar a imagem para o novo diretório de destino.
        Adaptar anotações:
            Se formato YOLO: Converter coordenadas COCO para coordenadas relativas normalizadas [x_{centro}, y_{centro}, w, h] e gerar arquivo .txt.
            Se formato Pascal VOC (SSD/Faster R-CNN): Converter coordenadas COCO para coordenadas absolutas [x_{min}, y_{min}, x_{max}, y_{max}] e gerar arquivo .xml. 

7. Gerar relatório
    Calcular:
        Quantidade de imagens por classe.
        Quantidade de objetos por classe.
        Estatísticas gerais do conjunto de dados.

8. Dividir o dataset
    Embaralhar as imagens.
    Separar em:
        Treinamento (80%).
        Validação (10%).
        Teste (10%).

9. Gerar arquivo de configuração
    Gerar arquivos de configuração:
        Se formato YOLO: Gerar o arquivo data.yaml contendo os caminhos do dataset, a quantidade de classes e os nomes das classes.
        Se formato Pascal VOC (SSD/Faster R-CNN): Gerar o arquivo label_map.pbtxt, contendo o mapeamento de IDs e nomes das classes no formato exigido pela API de detecção do TensorFlow.

10. Compactar o dataset
    Gerar um arquivo ZIP contendo toda a estrutura do dataset.

FIM
